  • Campaign from the printed code; mail drop from the postmark date; mailing list entry from donor + drop. That entry holds the address that was mailed, so "same address?" compares like with like.
  • If the printed code is unreadable but the donor code is read, the mailing list entry still gives the campaign and drop.
  • Campaign totals are roll-ups over Mail return, grouped by campaign and drop; return rate = returns ÷ mailing list entries. Nothing is copied into the campaign record, so totals stay right when a return is corrected.
  • In Zoho Creator these are lookup fields; deleting a campaign or drop with returns is blocked.

Found in the scans

  • Two donors had CRY's own address (Braintree MA 02185). One reads "Wellsfargo Via Your Cause": a fiduciary gift entered with a placeholder address and then mailed. Rule: never mail an address with CRY's ZIP 02185 or the words "via"; set them Not mailable at entry.
  • One duplicate donor: US-2024-000118 and US-2020-000129 are the same person at the same address; both were mailed.
  • One printing fault: two address labels printed on top of each other.
  • 7 attempted-not-known and 4 moved: Smarty confirms that an address exists, not that the donor still lives there. A change-of-address (NCOA) check before each mailing would catch many of these.
  • Not every envelope is a mailer: a bank envelope was in the scan; it is skipped because it has no CRY donor code.

Donor list scrub · offline mailer

Offline mailer
Mailable = a Smarty-valid US address that has not come back from a mailer since it was last changed. Not mailable = returned by USPS, no real address (e.g. CRY's own ZIP), or the donor asked for no mail. The list shows {{ mWhich }}.

When an address becomes Mailable again

  1. A new gift, import, API pull or tele-calling update brings an address for a Not-mailable donor.
  2. The CRM compares it with the returned address (Smarty-standardised, ZIP+4).
  3. Same address → stays Not mailable; the gift is saved as usual.
  4. Different address → Smarty check. Valid (DPV confirmed) → address updated and status set to Mailable, logged with the source. Not valid → stays Not mailable and goes to review.
  5. A forwarding address printed by USPS (FTE) goes through the same Smarty check, then staff confirm before it replaces the old one.

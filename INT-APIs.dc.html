Build notes for Zoho Creator

• One scheduled workflow per source (Deluge invokeUrl with a Creator Connection holding the credential); each writes raw rows to a staging form before matching. • Every record is keyed on the source ID (Givebutter id, Auth.net transId, PayPal transaction_id, Event Espresso PAY_ID) so a re-run never duplicates. • Pages: Auth.net paging limit/offset (1,000), PayPal page/page_size (500), Givebutter links.next, Event Espresso limit=offset,count + X-WP-TotalPages. • If a run outgrows Creator's script limits, move the pull into a Zoho Catalyst cron function that writes to Creator. • Failures (expired key, HTTP 4xx/5xx) alert Finance and the run is retried next hour; nothing posts to QuickBooks from a partial run.

Matching order

Against ~50,000 migrated donors
  1. Same gateway customer ID (Givebutter Contact ID, Auth.net subscription)
  2. Same email and same last name
  3. Same 10-digit phone and same last name
  4. Same first name + last name + ZIP5
  5. Near match (last name + ZIP5 + first initial, or street + ZIP5) → review, never auto
  6. Nothing → new donor with Donor Code US-2026-NNNNNN
